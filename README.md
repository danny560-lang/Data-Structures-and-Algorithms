# Data Structures and Algorithms

Data structures and algorithms implemented from scratch in Python for SNHU graduate coursework.

| Folder | What it is |
|---|---|
| `heap-sort-app/` | A hand-written heap sort over pipe-delimited data sets, with binary search lookup, a benchmark script and screenshots of the results |
| `avl-tree-search/` | A self-balancing AVL tree built without library data structures, plus a search that reports matches, counts and nodes visited |
| `recursive-catalog/` | Recursion, functional programming and exception handling over a nested astronomy catalog (JSON) |

Only the first, small sample data set is included in each folder. The full data sets are too large for GitHub.

## Running
```
python heap-sort-app/heap_sort_app.py
python avl-tree-search/avl_search.py
python recursive-catalog/recursive_catalog.py
```
